## Search by Technique

### Server Header Matching (~25 queries)
Queries using `"Server: [value]"` pattern

- Samsung Billboards, Yawcams, Logitech Media, Plex, Bomgar, HP Printers, etc.
- **Learn more**: [DOCUMENTATION.md - Server Headers](DOCUMENTATION.md#using-http-headers)

### HTTP Title Matching (~12 queries)
Queries using `http.title:"[title]"` pattern

- Tesla PowerPack, Jenkins, OctoPrint, Polycom, Nordex, Submarine Control, etc.
- **Learn more**: [DOCUMENTATION.md - HTTP Title Matching](DOCUMENTATION.md#using-http-headers)

### Port Filtering (~20 queries)
Queries using `port:[number]` pattern

- MongoDB (27017), Docker (2375), FTP (21), Telnet (23), RDP, VNC, etc.
- **Learn more**: [DOCUMENTATION.md - Port Filtering](DOCUMENTATION.md#common-filters)

### Content/Banner Matching (~30 queries)
Queries using `"[exact phrase]"` pattern

- "authentication disabled", "in-tank inventory", "ANPR enabled", etc.
- **Learn more**: [DOCUMENTATION.md - Search Operators](DOCUMENTATION.md#search-operators)

### Negative Filtering (~8 queries)
Queries using `-[term]` or `!"[exact]"` to exclude results

- MongoDB -authentication, HP iLO excluding patched versions, etc.
- **Learn more**: [DOCUMENTATION.md - Negative Filters](DOCUMENTATION.md#search-operators)

### SSL Certificate Matching (~2 queries)
Queries using `ssl:"[value]"` pattern

- Xerox Generic Root certificates
- **Learn more**: [DOCUMENTATION.md - SSL Certificates](DOCUMENTATION.md#ssl-certificate-hunting)

### Favicon Hash (~4 queries)
Queries using `http.favicon.hash:[number]` pattern

- OctoPrint, Exchange 2010, etc.
- **Learn more**: [DOCUMENTATION.md - Favicon Hashing](DOCUMENTATION.md#favicon-hashing)

### Boolean Operations (~3 queries)
Queries using `OR`, `AND` operators

- Maritime Satellites: `"Cobham SATCOM" OR ("Sailor" "VSAT")`
- **Learn more**: [DOCUMENTATION.md - Boolean Operators](DOCUMENTATION.md#search-operators)
